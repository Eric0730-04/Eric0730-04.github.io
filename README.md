# Eric Sun's portfolio

Personal portfolio covering data analytics, financial analysis, machine learning, and AI-agent projects.

**Website:** [eric0730-04.github.io](https://eric0730-04.github.io/)

The site is buildless HTML, CSS, and JavaScript, deployed by GitHub Pages from the root of `main`.

## Content

- Current academic consulting: customer lifetime value modelling with Propel Holdings.
- Featured work: SecondLook, 8-K Revision Agent, and Return Detective.
- Academic projects, professional experience, skills, education, and personal interests.
- The SecondLook video is streamed from the project's existing GitHub Release asset. A download link remains available.

## Preview locally

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`.

Content is in `index.html`, layout in `styles.css`, and navigation/video interactions in `script.js`. Optimized public assets live in `assets/`.
